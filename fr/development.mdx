<Info>
  **Prérequis :** Vous devez avoir installé Node.js (version 18.10.0 ou supérieure).
</Info>

Étape 1. Installez Mintlify sur votre OS :

<CodeGroup>
```bash npm
npm i -g mintlify
```

```bash yarn
yarn global add mintlify
```
</CodeGroup>

Étape 2. Allez là où se situe la documentation (là où se trouve `docs.json`) et exécutez la commande suivante :

```bash
mintlify dev
```

Le site de documentation est maintenant disponible sur `http://localhost:3000`.

### Ports personnalisés

Mintlify utilise le port 3000 par défaut. Vous pouvez utiliser l'indicateur `--port` pour personnaliser le port sur lequel Mintlify s'exécute. Par exemple, utilisez cette commande pour exécuter sur le port 3333 :

```bash
mintlify dev --port 3333
```

Vous verrez une erreur comme celle-ci si vous essayez d'exécuter Mintlify sur un port déjà utilisé :

```md
Error: listen EADDRINUSE: address already in use :::3000
```

## Versions de Mintlify

Chaque CLI est liée à une version spécifique de Mintlify. Veuillez mettre à jour la CLI si votre site local semble différent de la production.

<CodeGroup>
```bash npm
npm i -g mintlify@latest
```

```bash yarn
yarn global upgrade mintlify
```
</CodeGroup>

## Dépannage

Voici comment résoudre certains problèmes courants lors de l'utilisation de la CLI.

<AccordionGroup>
  <Accordion title="Mintlify ne se charge pas">
    Mettez à jour vers Node v18. Exécutez `mintlify install` et réessayez.
  </Accordion>
  <Accordion title="Fichier ou répertoire introuvable sur Windows">
    Allez dans le répertoire `C:/Users/NomUtilisateur/.mintlify/` et supprimez le dossier `mint`. Ensuite, ouvrez Git Bash à cet emplacement et exécutez `git clone https://github.com/mintlify/mint.git`.

    Répétez l'étape 3.
  </Accordion>
  <Accordion title="Obtention d'une erreur inconnue">
    Essayez de naviguer à la racine de votre appareil et supprimez le dossier ~/.mintlify. Ensuite, exécutez à nouveau `mintlify dev`.
  </Accordion>
</AccordionGroup>
