---
title: "Pays pris en charge"
sidebarTitle: "Pays pris en charge"
description: "Pays dont vous pouvez vérifier les passeports."
---

Vous pouvez vérifier un passeport de n'importe quel pays avec le [Passeport global](/fr/v3/kyc/document_verification/global/Passport), notamment le Nigeria, le Kenya, le Ghana, la Côte d'Ivoire, le Canada, les États-Unis, le Royaume-Uni, l'Afrique du Sud, l'Australie, le Burundi, la Chine, le Congo, l'Éthiopie, la Gambie, l'Inde, l'Indonésie, le Japon, l'Ouganda, le Rwanda, la Sierra Leone, la Somalie, le Soudan du Sud, la Tanzanie, le Togo, le Zimbabwe et d'autres pays.
