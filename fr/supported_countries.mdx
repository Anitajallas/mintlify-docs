---
title: "Pays pris en charge"
sidebarTitle: "Pays pris en charge"
description: "Pays dont vous pouvez vérifier les passeports."
---

Vous pouvez vérifier un passeport de n'importe quel pays avec le [Passeport global](/fr/v3/kyc/document_verification/global/Passport), notamment l'Afrique du Sud, l'Australie, le Burundi, le Canada, la Chine, le Congo, la Côte d'Ivoire, les États-Unis, l'Éthiopie, la Gambie, le Ghana, l'Inde, l'Indonésie, le Japon, le Kenya, le Nigeria, l'Ouganda, le Royaume-Uni, le Rwanda, la Sierra Leone, la Somalie, le Soudan du Sud, la Tanzanie, le Togo, le Zimbabwe et d'autres pays.
