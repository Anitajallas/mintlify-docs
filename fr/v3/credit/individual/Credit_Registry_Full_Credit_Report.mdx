L'endpoint Rapport de crédit complet Credit Registry renvoie un rapport de crédit complet auprès du bureau Credit Registry, notamment l'historique de prêt, la performance de remboursement, les détails des créanciers, les demandes de crédit et un résumé des demandes.

## Endpoint

```
POST /api/onboarding/individual/credit_registry_full/
```

## Requête

### En-têtes

| En-tête | Valeur | Requis |
|--------|-------|----------|
| `x-access-token` | Votre clé secrète API | Oui |
| `Content-Type` | `application/json` | Oui |

### Paramètres de corps

| Paramètre | Type | Requis | Description |
|-----------|------|----------|-------------|
| `bvn` | string | Oui | Le numéro d'identification bancaire à 11 chiffres de l'individu |

### Exemple

<CodeGroup>
```bash cURL
curl -X POST "https://adhere-api.smartcomply.com/api/onboarding/individual/credit_registry_full/" \
  -H "x-access-token: YOUR_SECRET_KEY" \
  -H "Content-Type: application/json" \
  -d '{"bvn": "22244545518"}'
```
</CodeGroup>

## Réponse

### 200 OK

| Champ | Type | Description |
|-------|------|-------------|
| `data.name` | string | Nom complet |
| `data.score.totalNoOfLoans` | number | Prêts totaux au dossier |
| `data.score.totalBorrowed` | number | Montant total emprunté |
| `data.score.creditors` | array | Liste des créanciers avec coordonnées de contact |
| `data.score.creditEnquiries` | array | Liste des demandes de crédit avec dates et raisons |
| `data.score.creditEnquiriesSummary` | object | Nombre de demandes pour les 3, 12 et 36 derniers mois |
| `data.score.loanPerformance` | array | Détails de performance de remboursement par compte |
| `data.score.loanHistory` | array | Historique détaillé prêt par prêt |
