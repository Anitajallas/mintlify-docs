---

L'endpoint Rapport de crédit individuel Premium agrège les données de crédit des bureaux Credit Registry et First Central, fournissant une vue unifiée de la solvabilité d'un individu, notamment l'historique de prêt, les créanciers, la performance et les demandes.

## Endpoint

```
POST /api/onboarding/individual/premium/
```

## Requête

### En-têtes

| En-tête | Valeur | Requis |
|--------|-------|----------|
| `x-access-token` | Votre clé secrète API | Oui |
| `Content-Type` | `application/json` | Oui |

### Paramètres de corps

| Paramètre | Type | Requis | Description |
|-----------|------|----------|-------------|
| `bvn` | string | Oui | Le numéro d'identification bancaire à 11 chiffres de l'individu |

### Exemple

<CodeGroup>
```bash cURL
curl -X POST "https://adhere-api.smartcomply.com/api/onboarding/individual/premium/" \
  -H "x-access-token: YOUR_SECRET_KEY" \
  -H "Content-Type: application/json" \
  -d '{"bvn": "22244545518"}'
```
</CodeGroup>

## Réponse

### 200 OK

| Champ | Type | Description |
|-------|------|-------------|
| `data.name` | string | Nom complet |
| `data.score.totalNoOfLoans` | number | Prêts totaux au dossier |
| `data.score.totalBorrowed` | number | Montant total emprunté |
| `data.score.creditors` | array | Liste des créanciers |
| `data.score.creditEnquiries` | array | Liste des demandes de crédit |
| `data.score.creditEnquiriesSummary` | object | Nombre de demandes par période |
| `data.score.loanPerformance` | array | Détails de performance par compte |
| `data.score.loanHistory` | array | Historique de prêt détaillé |
