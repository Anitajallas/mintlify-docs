---

L'endpoint Score de crédit First Central renvoie le score de crédit à la consommation d'un individu auprès du bureau First Central, accompagné de résumés d'état des comptes, des totaux de dettes impayées et des métriques de décomposition du score.

## Endpoint

```
POST /api/onboarding/individual/credit_scores_first_central/
```

## Requête

### En-têtes

| En-tête | Valeur | Requis |
|--------|-------|----------|
| `x-access-token` | Votre clé secrète API | Oui |
| `Content-Type` | `application/json` | Oui |

### Paramètres de corps

| Paramètre | Type | Requis | Description |
|-----------|------|----------|-------------|
| `bvn` | string | Oui | Le numéro d'identification bancaire à 11 chiffres de l'individu |

### Exemple

<CodeGroup>
```bash cURL
curl -X POST "https://adhere-api.smartcomply.com/api/onboarding/individual/credit_scores_first_central/" \
  -H "x-access-token: YOUR_SECRET_KEY" \
  -H "Content-Type: application/json" \
  -d '{"bvn": "22244545518"}'
```
</CodeGroup>

## Réponse

### 200 OK

| Champ | Type | Description |
|-------|------|-------------|
| `data.score.totalConsumerScore` | string | Score de crédit global du consommateur |
| `data.score.description` | string | Évaluation du risque (p. ex. `"LOW RISK"`, `"HIGH RISK"`) |
| `data.score.totalAccounts` | string | Comptes totaux au dossier |
| `data.score.totalaccountinGoodcondition` | string | Comptes en bonne situation |
| `data.score.totalaccountinBadcondition` | string | Comptes en mauvaise situation |
| `data.score.totalOutstandingDebt` | string | Dette impayée totale |
| `data.score.totalAmountOverdue` | string | Montant total en retard |
| `data.score.repaymentHistoryScore` | string | Composante du score d'historique de remboursement |
| `data.score.firstCentralEnquiryResultID` | string | Identifiant du résultat de demande First Central |
