L'endpoint National ID avancé renvoie des informations d'identité complètes pour un national ID kényan, incluant la photo de l'inscrit, le lieu de naissance, le lieu de résidence et les détails de délivrance.

## Endpoint

```
POST /api/onboarding/kenya_kyc/national_id_advance/
```

## Requête

### En-têtes

| En-tête | Valeur | Requis |
|--------|-------|----------|
| `x-access-token` | Votre clé secrète API | Oui |
| `Content-Type` | `application/json` | Oui |

### Paramètres de corps

| Paramètre | Type | Requis | Description |
|-----------|------|----------|-------------|
| `national_id` | integer | Oui | Le numéro de national ID kényan du client |

### Exemple

<CodeGroup>
```bash cURL
curl -X POST "https://adhere-api.smartcomply.com/api/onboarding/kenya_kyc/national_id_advance/" \
  -H "x-access-token: YOUR_SECRET_KEY" \
  -H "Content-Type: application/json" \
  -d '{"national_id": 1010101010}'
```
</CodeGroup>

## Réponse

### 200 OK

| Champ | Type | Description |
|-------|------|-------------|
| `data.First_Name` | string | Prénom |
| `data.Surname` | string | Nom de famille |
| `data.Other_Name` | string | Autre/deuxième prénom |
| `data.Gender` | string | Genre (`"M"` ou `"F"`) |
| `data.Date_of_Birth` | string | Date de naissance |
| `data.Citizenship` | string | Statut de citoyenneté |
| `data.Date_of_Issue` | string | Date de délivrance de la carte d'identité |
| `data.Place_of_Birth` | string | Lieu de naissance |
| `data.Place_of_Live` | string | Lieu de résidence enregistré |
| `data.Photo` | string | Photo de la carte d'identité encodée en base64 |
