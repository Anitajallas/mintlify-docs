L'endpoint CAC Avancé renvoie un profil d'entreprise complet depuis la Corporate Affairs Commission, incluant la liste complète des directeurs, leurs détails personnels, les informations de participation et les données PSC affiliées.

## Endpoint

```
POST /api/onboarding/nigeria_kyc/cac_advanced/
```

## Requête

### En-têtes

| En-tête | Valeur | Requis |
|--------|-------|----------|
| `x-access-token` | Votre clé secrète API | Oui |
| `Content-Type` | `application/json` | Oui |

### Paramètres de corps

| Paramètre | Type | Requis | Description |
|-----------|------|----------|-------------|
| `registration_number` | string | Oui | Le numéro d'enregistrement CAC |
| `company_name` | string | Oui | Nom de l'entreprise enregistré |
| `company_type` | string | Oui | Type d'entité : `"RC"` (société enregistrée), `"BN"` (nom commercial) ou `"IT"` (fiduciaire incorporé) |

### Exemple

<CodeGroup>
```bash cURL
curl -X POST "https://adhere-api.smartcomply.com/api/onboarding/nigeria_kyc/cac_advanced/" \
  -H "x-access-token: YOUR_SECRET_KEY" \
  -H "Content-Type: application/json" \
  -d '{"registration_number": "10056", "company_name": "JOYCE VENTURES", "company_type": "IT"}'
```

```python Python
import requests
response = requests.post(
    "https://adhere-api.smartcomply.com/api/onboarding/nigeria_kyc/cac_advanced/",
    headers={"x-access-token": "YOUR_SECRET_KEY", "Content-Type": "application/json"},
    json={"registration_number": "10056", "company_name": "JOYCE VENTURES", "company_type": "IT"},
)
```
</CodeGroup>

## Réponse

### 200 OK

| Champ | Type | Description |
|-------|------|-------------|
| `data.rc_number` | string | Numéro d'enregistrement |
| `data.company_name` | string | Nom de l'entreprise |
| `data.company_id` | integer | ID interne de l'entreprise |
| `data.entity_type` | string | Type d'entité (par ex. `"IT"`, `"RC"`, `"BN"`) |
| `data.company_status` | string | Par ex. `"ACTIVE"` |
| `data.registrationDate` | string | Date d'enregistrement |
| `data.directors` | array | Liste des directeurs avec leurs détails personnels et de participation complets |
| `data.directors[].firstname` | string | Prénom du directeur |
| `data.directors[].surname` | string | Nom de famille du directeur |
| `data.directors[].gender` | string | Genre du directeur |
| `data.directors[].status` | string | Statut du directeur (par ex. `"ACTIVE"`) |
| `data.directors[].isChairman` | boolean | `true` si le directeur est le président |
| `data.directors[].dateOfAppointment` | string | Date de nomination |
