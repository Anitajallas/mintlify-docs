</Warning>

L'endpoint Permis de conduire récupère les informations d'identité vérifiées depuis la base de données FRSC, incluant le nom, la date de naissance, les dates de validité du permis, l'État de délivrance et une photo.

## Endpoint

```
POST /api/onboarding/nigeria_kyc/driver_license/
```

## Requête

### En-têtes

| En-tête | Valeur | Requis |
|--------|-------|----------|
| `x-access-token` | Votre clé secrète API | Oui |
| `Content-Type` | `application/json` | Oui |

### Paramètres de corps

| Paramètre | Type | Requis | Description |
|-----------|------|----------|-------------|
| `license_number` | string | Oui | Le numéro de permis de conduire du client |
| `first_name` | string | Oui | Prénom tel qu'il apparaît sur le permis |
| `last_name` | string | Oui | Nom de famille tel qu'il apparaît sur le permis |
| `date_of_birth` | string | Oui | Date de naissance au format `YYYY-MM-DD` |

### Exemple

<CodeGroup>
```bash cURL
curl -X POST "https://adhere-api.smartcomply.com/api/onboarding/nigeria_kyc/driver_license/" \
  -H "x-access-token: YOUR_SECRET_KEY" \
  -H "Content-Type: application/json" \
  -d '{"license_number": "ARR10892UU00", "first_name": "EDIKAN", "last_name": "EFE", "date_of_birth": "1994-08-11"}'
```

```python Python
import requests
response = requests.post(
    "https://adhere-api.smartcomply.com/api/onboarding/nigeria_kyc/driver_license/",
    headers={"x-access-token": "YOUR_SECRET_KEY", "Content-Type": "application/json"},
    json={"license_number": "ARR10892UU00", "first_name": "EDIKAN", "last_name": "EFE", "date_of_birth": "1994-08-11"},
)
```
</CodeGroup>

## Réponse

### 200 OK

| Champ | Type | Description |
|-------|------|-------------|
| `data.licenseNo` | string | Numéro de permis |
| `data.lastName` | string | Nom de famille |
| `data.firstName` | string | Prénom |
| `data.middleName` | string | Deuxième prénom |
| `data.gender` | string | Genre |
| `data.dateOfBirth` | string | Date de naissance |
| `data.issuedDate` | string | Date de délivrance du permis |
| `data.expiryDate` | string | Date d'expiration du permis |
| `data.stateOfIssue` | string | État où le permis a été délivré |
| `data.image` | string | Photo du permis encodée en base64 |
