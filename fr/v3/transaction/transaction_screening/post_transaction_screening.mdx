---

L'endpoint Filtrer une transaction évalue une transaction par rapport à des critères de conformité prédéfinis, notamment les listes de sanctions, les indicateurs de pays à haut risque et les mots-clés suspects. Les transactions correspondant à l'un de ces critères sont signalées pour examen.

## Endpoint

```
POST /api/v1/monitoring/transaction_screening
```

## Requête

### En-têtes

| En-tête | Valeur | Requis |
|--------|-------|----------|
| `x-access-token` | Votre clé secrète API | Oui |
| `Content-Type` | `application/json` | Oui |

### Paramètres de corps

| Paramètre | Type | Requis | Description |
|-----------|------|----------|-------------|
| `transactionId` | string | Recommandé | Associe les appels répétés à la même transaction |
| `transactionType` | string | Facultatif | p. ex., `Transfer`, `Payment` |
| `amount` | number | **Requis** | Montant de la transaction (p. ex., `10000.00`) |
| `currency` | string | Facultatif | Code de devise, p. ex., `NGN`, `USD` |
| `transactionDate` | string | **Requis** | Date-heure ISO-8601, p. ex., `2024-07-06T12:34:56Z` |
| `sender.name` | string | **Requis** | Nom complet de l'expéditeur — filtré par rapport aux listes de risques |
| `sender.accountNumber` | string | Facultatif | Numéro de compte de l'expéditeur |
| `sender.address` | object | Facultatif | Adresse de l'expéditeur pour les contrôles basés sur la localisation |
| `sender.address.country` | string | Recommandé | Aide à signaler les pays à haut risque |
| `sender.identification` | object | Facultatif | Détails de l'ID de l'expéditeur |
| `receiver.name` | string | **Requis** | Nom complet du destinataire — filtré par rapport aux listes de risques |
| `receiver.accountNumber` | string | Facultatif | Numéro de compte du destinataire |
| `receiver.address` | object | Facultatif | Adresse du destinataire pour les contrôles basés sur la localisation |
| `receiver.address.country` | string | Recommandé | Aide à signaler les pays à haut risque |
| `receiver.identification` | object | Facultatif | Détails de l'ID du destinataire |
| `details.purpose` | string | Recommandé | Objet de la transaction — utilisé pour le filtrage par mots-clés |
| `details.reference` | string | Facultatif | Votre référence interne ou numéro de facture |

## Réponse

### 201 Created — Signalé

Lorsque la transaction correspond à un critère de filtrage, la réponse inclut les détails complets de la correspondance de sanctions pour l'expéditeur et le destinataire.

| Champ | Type | Description |
|-------|------|-------------|
| `data.transactionId` | string | Identifiant de la transaction |
| `data.amount` | number | Montant de la transaction |
| `data.currency` | string | Code de devise |
| `data.sender` | object | Détails de l'expéditeur renvoyés en écho |
| `data.receiver` | object | Détails du destinataire renvoyés en écho |
| `data.sanction.sender_name` | string | Nom de l'expéditeur filtré |
| `data.sanction.sender_record` | array | Correspondances de sanctions pour l'expéditeur |
| `data.sanction.receiver_name` | string | Nom du destinataire filtré |
| `data.sanction.receiver_record` | array | Correspondances de sanctions pour le destinataire |
| `data.sanction[].entity_name` | string | Nom de l'entité sanctionnée correspondante |
| `data.sanction[].entity_type` | string | Type d'entité (p. ex., `Person`) |
| `data.sanction[].topics` | array | Catégories de sanctions (p. ex., `sanction`, `crime.terror`) |
| `data.sanction[].match_score` | number | Score de confiance de correspondance (0 à 1) |
| `data.screeningStatus` | string | Résultat : `"flagged"` ou `"approved"` |
| `data.sender_risk_level` | string | Niveau de risque de l'expéditeur : `"low"`, `"medium"` ou `"high"` |
| `data.receiver_risk_level` | string | Niveau de risque du destinataire : `"low"`, `"medium"` ou `"high"` |
| `data.comments` | string | Raison du résultat de filtrage |
| `data.additionalActions` | array | Actions de suivi recommandées |
| `data.additionalActions[].actionType` | string | Type d'action (p. ex., `"Notify Customer"`) |
| `data.additionalActions[].assignedTo` | string | Équipe ou personne responsable |
| `data.additionalActions[].notes` | string | Instructions pour l'action |
| `data.summary` | object | Résumé des résultats de filtrage |
| `data.summary.verdict` | string | Verdict global du filtrage |
| `data.summary.sender_risk_level` | string | Niveau de risque de l'expéditeur |
| `data.summary.receiver_risk_level` | string | Niveau de risque du destinataire |
| `data.summary.sender_matches` | object | Détails des correspondances de l'expéditeur |
| `data.summary.sender_matches.matched_status` | boolean | Si l'expéditeur avait des correspondances |
| `data.summary.sender_matches.highest_match_score` | string | Pourcentage de score de correspondance le plus élevé |
| `data.summary.sender_matches.sanctions_count` | number | Nombre de correspondances de sanctions |
| `data.summary.sender_matches.peps_count` | number | Nombre de correspondances PEP |
| `data.summary.sender_matches.on_blacklist` | boolean | Si l'expéditeur est sur liste noire |
| `data.summary.receiver_matches` | object | Détails des correspondances du destinataire |
| `data.summary.receiver_matches.matched_status` | boolean | Si le destinataire avait des correspondances |
| `data.summary.receiver_matches.highest_match_score` | string | Pourcentage de score de correspondance le plus élevé |
| `data.summary.receiver_matches.sanctions_count` | number | Nombre de correspondances de sanctions |
| `data.summary.receiver_matches.peps_count` | number | Nombre de correspondances PEP |
| `data.summary.receiver_matches.on_blacklist` | boolean | Si le destinataire est sur liste noire |
