Verify a customer's passport from any country by uploading a photo of the data page. We read the details with OCR, confirm which country issued the passport, and compare the face on the passport with a selfie.

<Note>
  Passport is single-sided. Only `document_front` is needed.
</Note>

<Note>
  `country` is optional. Send it when you know which country issued the passport. Leave it out and we detect the country from the passport itself.
</Note>

## Endpoint

```
POST /api/onboarding/document_verification/passport
```

## Request

### Headers

| Header | Value | Required |
|--------|-------|----------|
| `x-access-token` | Your API secret key | Yes |
| `Content-Type` | `multipart/form-data` | Yes |

### Body Parameters

| Parameter | Type | Required | Description |
|-----------|------|----------|--------------|
| `document_front` | file | Yes | Photo or scan of the passport data page. JPG, PNG or single-page PDF, max 10MB |
| `selfie_image` | file | Yes | A selfie to compare against the face on the passport. JPG or PNG, max 5MB |
| `country` | string | No | The country that issued the passport, as an ISO 3166-1 alpha-2 code, for example `RW`. Leave it out to have it detected |

<Tip>
  A scanned document can be uploaded as a single-page PDF, for example `-F "document_front=@/path/to/scan.pdf"`.
</Tip>

### Example

<CodeGroup>
```bash cURL
curl -X POST "https://adhere-api.smartcomply.com/api/onboarding/document_verification/passport" \
  -H "x-access-token: YOUR_SECRET_KEY" \
  -F "document_front=@/path/to/passport.jpg" \
  -F "selfie_image=@/path/to/selfie.jpg" \
  -F "country=RW"
```

```javascript Node.js
const formData = new FormData();
formData.append("document_front", fs.createReadStream("/path/to/passport.pdf"));
formData.append("selfie_image", fs.createReadStream("/path/to/selfie.jpg"));
formData.append("country", "RW"); // optional

const response = await fetch(
  "https://adhere-api.smartcomply.com/api/onboarding/document_verification/passport",
  {
    method: "POST",
    headers: { "x-access-token": "YOUR_SECRET_KEY" },
    body: formData,
  }
);
const data = await response.json();
```

```python Python
import requests

response = requests.post(
    "https://adhere-api.smartcomply.com/api/onboarding/document_verification/passport",
    headers={"x-access-token": "YOUR_SECRET_KEY"},
    data={"country": "RW"},  # optional
    files={
        "document_front": open("/path/to/passport.jpg", "rb"),
        "selfie_image": open("/path/to/selfie.jpg", "rb"),
    },
)
data = response.json()
```
</CodeGroup>

## Response

### 200 OK

| Field | Type | Description |
|-------|------|--------------|
| `status` | string | `"success"` on a successful extraction |
| `data.full_name` | string | Extracted full name |
| `data.first_name` | string | Extracted first name |
| `data.last_name` | string | Extracted last name |
| `data.date_of_birth` | string | Date of birth in `YYYY-MM-DD` format |
| `data.gender` | string | Extracted gender |
| `data.nationality` | string | Extracted nationality |
| `data.id_number` | string | The passport number |
| `data.document_type` | string | `"passport"` |
| `data.document_country` | string | The country that issued the passport, as an ISO 3166-1 alpha-2 code, for example `"RW"` |
| `data.expiry_date` | string | Passport expiry date |
| `data.is_expired` | boolean | Always `false` on a 200. An expired passport fails the check (see [Expired passports](#expired-passports)) |
| `data.photo` | string | Base64-encoded face photo extracted from the passport |
| `data.extra_fields` | object | Other fields read from the data page, such as `place_of_birth`, `place_of_issue`, `issuing_authority`, and `mrz_line1`/`mrz_line2` when the machine-readable zone was legible |
| `data.face_match` | object | Result of comparing the face on the passport with `selfie_image` |
| `data.face_match.attempted` | boolean | Whether a comparison was run |
| `data.face_match.verified` | boolean \| null | `true` or `false` if the comparison ran; `null` if it couldn't run |
| `data.face_match.decision` | string | `"MATCH"` or `"NO_MATCH"` |
| `data.face_match.confidence_percentage` | number | Match confidence, 0 to 100 |
| `data.face_match.compare_mode` | string | `"COMPARISON_NO_LIVENESS"`: the two photos are compared; no liveness check is run on the selfie |
| `data.face_match.selfie_image` | string | URL of the uploaded selfie |
| `message` | string | Human-readable result summary |

```json

  "data": {
    "valid": true,

    "last_name": "Ngarango",
```

<Note>
  **Face match:** `verified: false` with `decision: "NO_MATCH"` means the comparison ran and the faces didn't match. `verified: null` with a `reason` means the comparison couldn't run, for example because no face was found in the selfie. A face-match problem never blocks the passport data: the rest of `data` is still returned.
</Note>

### 400 Bad Request

The passport wasn't issued by the `country` you sent:

```json
{
  "status": "failed",
  "data": {
    "error_code": "VERIFICATION_FAILED"
  },
  "message": "Document Verification - Passport check failed: This document wasn't issued by the country you chose. Please upload a document from that country"
}
```

Passports from this country can't be verified:

```json
{
  "status": "failed",
  "data": [],
  "message": "Passports from this country can't be verified."
}
```

The photo can't be read, for example because part of the passport is cut off:

```json
{
  "status": "failed",
  "data": {
    "error_code": "VERIFICATION_FAILED"
  },
  "message": "Document Verification - Passport check failed: Part of the document is cut off in the photo. Please retake with all edges and corners fully visible."
}
```

### Expired passports

An expired passport fails the check. The extracted details are still returned in `data`, with `is_expired: true`:

```json
{
  "status": "failed",
  "data": {
    "first_name": "Nassra Nassor",
    "last_name": "Ngarango",
    "id_number": "TAE661142",
    "document_type": "passport",
    "document_country": "TZ",
    "expiry_date": "2021-11-08",
    "is_expired": true
  },
  "message": "Document Verification - Passport check failed: Document has expired."
}
```

### 401 Unauthorized

```json
{
  "status": "failed",
  "message": "Authentication credentials were not provided."
}
```

<Note>
  For a full list of error codes, see the [Error Codes](/error_codes) reference.
</Note>
